# AUGMENT CHESS · 증강체스

**[브라우저에서 플레이](https://leejuhan-1214.github.io/augment-chess/)**

체스의 기본 규칙에 세 번의 증강 선택을 더한 한국어 브라우저 게임입니다. 설치와 로그인 없이 플레이합니다.

## 대전 모드

- **온라인 친구 대전**: 방을 만들고 8자리 코드나 초대 링크를 공유합니다. 방장은 백, 친구는 흑입니다. 연결되면 증강 선택과 모든 이동이 동기화됩니다.
- **AI 연습**: 두 수 앞을 탐색하는 간단한 AI와 대전합니다.
- **로컬 2인**: 같은 기기에서 백과 흑을 번갈아 조작합니다.

온라인은 **초대 기반 1:1 대전**입니다. 자동 매칭, 랭킹, 계정, 서버 영구 저장은 없습니다.

## 규칙

대전 시작 전, 6라운드 종료 후, 12라운드 종료 후에 각각 무작위 증강 세 가지 중 하나를 선택합니다. 백 다음 흑 순서이며, 총 세 가지 능력이 중첩됩니다. 선택 즉시 적용되므로 새로운 체크가 발생할 수 있습니다. 상대의 선택도 공개됩니다.

| 증강 | 효과 |
| --- | --- |
| 자유로운 기사 | 나이트가 상하좌우 한 칸도 이동·공격 |
| 전장의 수도사 | 비숍이 상하좌우 한 칸도 이동·공격 |
| 기울어진 성벽 | 룩이 대각선 한 칸도 이동·공격 |
| 측면의 송곳니 | 폰이 바로 좌우의 적도 포획 |
| 선봉대 | 시작 줄 폰의 첫 전진이 최대 세 칸 |
| 전술적 후퇴 | 폰이 뒤로 한 칸 비포획 이동 |
| 왕의 도약 | 킹이 나이트 이동·공격도 사용 |
| 차원을 걷는 여왕 | 퀸이 나이트 이동·공격도 사용 |

추가 공격 범위도 체크·캐슬링의 안전 판정에 반영됩니다. 체크메이트, 스테일메이트, 캐슬링, 앙파상, 선택 승급, 동일 포지션 3회 반복, 50수 규칙, 합의 무승부와 기권을 지원합니다. 증강이 없을 때의 간단한 기물 부족 포지션도 판정합니다. 증강 적용 후의 기물 부족은 자동 판정하지 않습니다. 폰의 세 칸 이동은 앙파상 대상이 아니며, 후퇴로 시작 줄에 돌아와도 첫 이동은 복구되지 않습니다.

## 온라인 연결과 제한

[PeerJS 1.5.5](https://peerjs.com/)와 공용 PeerServer로 연결을 중개하고, WebRTC 데이터 채널로 게임을 전달합니다. 계정·API 키·카메라·마이크는 필요하지 않습니다. IP 주소 등 WebRTC 연결 메타데이터가 상대와 연결 서비스에 전달될 수 있습니다. 방 코드는 친구에게만 공유하세요.

방장이 두 플레이어의 명령을 검증하고 확정된 상태를 전송합니다. 차례가 아닌 명령, 잘못된 수, 제공되지 않은 증강, 오래된 상태에 대한 명령을 거부합니다. 이는 친구 간 캐주얼 플레이용이며, 방장이 코드를 변조하는 것까지 방지하는 경쟁용 서버 검증은 아닙니다.

두 사람 모두 탭을 열어 두세요. 데이터 연결이 잠깐 끊겼다면 **다시 연결하기**로 이어갈 수 있습니다. 참가자는 같은 브라우저 탭을 새로고침해도 세션 토큰이 남아 있으면 같은 코드로 재입장할 수 있습니다. **방장 탭을 닫거나 새로고침하면 게임이 사라집니다.** 별도의 영구 저장은 없습니다. 일부 엄격한 NAT, 회사·학교·이동통신 네트워크에서는 공용 중계만으로 연결되지 않을 수 있습니다. 네트워크를 바꾸거나 자체 PeerServer/TURN을 구성해야 합니다. 공용 서비스의 가동률은 보장하지 않습니다.

## 개발

Node.js 20 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
```

- `engine.js`: DOM 없는 체스 규칙, 증강, 상태 reducer, AI
- `network.js`: 방 생성, 접속, 상대 제한, 재연결, 데이터 채널
- `app.js`: 한국어 UI, 대전 흐름, 동기화, 접근성
- `engine.test.js`, `network.test.js`: 규칙 및 온라인 프로토콜 테스트
- `index.html`, `style.css`, `favicon.svg`: 화면
- `peerjs.min.js`: 고정 버전 배포 파일, MIT 고지는 `PEERJS-LICENSE` 참고

GitHub Pages는 `main` 브랜치의 루트(`/`)를 배포합니다. 빌드 과정과 별도 서버는 필요하지 않습니다. 폰트만 Google Fonts에서 선택적으로 로드하며 로드되지 않으면 시스템 폰트로 표시됩니다.

## 검증

기본 시작 포지션의 perft 참조값 20 / 400 / 8902, 캐슬링 안전성, 앙파상 핀, 선택 승급, 증강 공격, 반복·체크메이트, 차례 및 revision 검증, 같은 시드의 결정적 상태, 온라인 채널 수명과 재연결을 테스트합니다.
