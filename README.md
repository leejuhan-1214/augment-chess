# AUGMENT CHESS · 증강체스

**[브라우저에서 플레이](https://leejuhan-1214.github.io/augment-chess/)**

체스의 기본 규칙에 세 번의 증강 선택을 더한 한국어 브라우저 게임입니다. 설치와 로그인 없이 플레이합니다.

## 대전 모드

- **온라인 친구 대전**: 방을 만들고 8자리 코드나 초대 링크를 공유합니다. 방장은 백, 친구는 흑입니다. 연결되면 증강 선택과 모든 이동이 동기화됩니다.
- **AI 연습**: 두 수 앞을 탐색하는 간단한 AI와 대전합니다.
- **로컬 2인**: 같은 기기에서 백과 흑을 번갈아 조작합니다.

온라인은 **초대 기반 1:1 대전**입니다. 자동 매칭, 랭킹, 계정, 서버 영구 저장은 없습니다.

## 규칙

대전 시작 전, 6라운드 종료 후, 12라운드 종료 후에 각각 무작위 증강 세 가지 중 하나를 선택합니다. 백 다음 흑 순서이며, 총 세 가지 능력이 중첩됩니다. 지속형은 즉시 적용되고, 발동형은 내 차례에 카드와 대상을 클릭해 이동 대신 사용합니다. 발동도 한 수/차례로 계산하며 킹을 체크에 남기는 행동은 거부합니다. 상대의 선택, 사용 횟수, 기물의 효과도 공개됩니다.

| 증강 | 효과 |
| --- | --- |
| 자유로운 기사 | 나이트가 상하좌우 한 칸도 이동·공격 |
| 전장의 수도사 | 비숍이 상하좌우 한 칸도 이동·공격 |
| 기울어진 성벽 | 룩이 대각선 한 칸도 이동·공격 |
| 측면의 송곳니 | 폰이 바로 좌우의 적도 포획 |
| 선봉대 | 시작 줄 폰의 첫 전진이 최대 세 칸 |
| 전술적 후퇴 | 폰이 뒤로 한 칸 비포획 이동 |
| 왕의 도약 | 킹이 나이트 이동·공격도 사용 |
| 차원을 걷는 여왕 | 퀸이 나이트 이동·공격도 사용 |

### 발동형 특수능력 8종

| 카드 | 대전당 사용 | 효과 |
| --- | --- | --- |
| 독자의 방벽 | 2회 | 아군 킹 이외 기물을 상대 다음 차례 끝까지 포획에서 보호 |
| 회귀의 잔향 | 1회 | 직전에 일반 이동한 아군 기물을 빈 출발 칸으로 복귀. 킹·승급·봉인 제외, 포획 복구 없음 |
| 별의 후원 | 1회 | 자신의 폰 시작 줄 빈칸에 폰 소환. 첫 이동 두·세 칸 전진 불가 |
| 기록의 재현 | 1회 | 상대가 가장 최근에 고른 지속형을 영구 복제. 이미 보유한 효과 제외 |
| 묘지의 부름 | 1회 | 가장 최근에 잃은 부활 가능한 기물을 뒤쪽 두 줄 빈칸에 부활. 킹·퀸 제외 |
| 제물의 왕관 | 1회 | 아군 폰 하나를 희생해 아군 룩을 퀸으로 변환. 룩과 파일이 가장 가까운 비봉인 폰, 동률은 a8→h1 순서 |
| 봉인의 사슬 | 2회 | 적 킹 이외 기물의 다음 차례 이동 봉인. 공격 범위는 유지 |
| 반격의 각인 | 1회 | 아군 비킹 기물에 공개 각인. 포획될 때 비킹 공격자도 함께 제거. 발동까지 유지 |

복제는 선택 슬롯 밖에 표시됩니다. 소환·부활·회귀는 첫 이동 및 캐슬링 권리를 복구하지 않습니다. 보호·봉인은 상대의 다음 차례 끝에 해제되며 증강 선택은 시간을 진행시키지 않습니다. 반격은 앙파상 포획에도 적용됩니다. 부활은 묘지에서 기물 하나를 제거하며 제물과 반격으로 잃은 기물도 묘지에 기록됩니다. AI도 발동형을 사용합니다.

로비에서 **모든 증강 살펴보기 → 이 카드로 AI 연습**을 선택하면 원하는 카드로 시작할 수 있습니다. 온라인의 무작위 선택에는 영향을 주지 않습니다.

### 캐슬링 조작

킹을 선택한 뒤 두 칸 옆의 도착 칸 또는 해당 룩을 클릭하세요. 데스크톱에서는 **O-O / O-O-O** 버튼도 제공합니다. 불가능한 버튼을 누르면 막힌 칸, 공격받는 칸, 움직인 기물 등의 이유를 안내합니다. 증강으로 늘어난 공격 범위도 안전 검사에 포함합니다. 봉인된 룩은 캐슬링에 참여하지 못합니다.

### 창작 참고

새 카드 이름과 체스 규칙은 독자적으로 만들었습니다. 전독시의 독자·서사·성좌 모티프는 [공식 작품 소개](https://www.webtoons.com/en/action/omniscient-reader/list?title_no=2154)와 [싱숑 공식 인터뷰](https://yenpress.com/news/exclusive-interview-with-singnsong-authors-of-omniscient-reader-s-viewpoint)를 참고했습니다. 소설 전체를 읽거나 원작 스킬을 그대로 재현한 것은 아닙니다.

부활·공격 반응·제물은 코나미의 [Monster Reborn](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=4842&ope=2), [Mirror Force](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=4887&ope=2&request_locale=en), [Fiendish Chain](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=8675&ope=2&request_locale=en), [공식 룰북](https://www.yugioh-card.com/eu/wp-content/uploads/2022/07/Rulebook_v9_en.pdf)에서 착안했습니다. 원작과 제휴한 공식 게임이 아닙니다.

추가 공격 범위도 체크·캐슬링의 안전 판정에 반영됩니다. 체크메이트, 스테일메이트, 캐슬링, 앙파상, 선택 승급, 동일 포지션 3회 반복, 50수 규칙, 합의 무승부와 기권을 지원합니다. 증강이 없을 때의 간단한 기물 부족 포지션도 판정합니다. 증강 적용 후의 기물 부족은 자동 판정하지 않습니다. 폰의 세 칸 이동은 앙파상 대상이 아니며, 후퇴로 시작 줄에 돌아와도 첫 이동은 복구되지 않습니다.

## 온라인 연결과 제한

[PeerJS 1.5.5](https://peerjs.com/)와 공용 PeerServer로 연결을 중개하고, WebRTC 데이터 채널로 게임을 전달합니다. 계정·API 키·카메라·마이크는 필요하지 않습니다. IP 주소 등 WebRTC 연결 메타데이터가 상대와 연결 서비스에 전달될 수 있습니다. 방 코드는 친구에게만 공유하세요.

방장이 두 플레이어의 명령을 검증하고 확정된 상태를 전송합니다. 차례가 아닌 명령, 잘못된 수, 제공되지 않은 증강, 남은 횟수가 없는 스킬, 잘못된 대상과 오래된 상태에 대한 명령을 거부합니다. 전송 시 큰 JSON 상태를 작은 조각으로 분리해 PeerJS JSON 채널의 16KB 메시지 제한을 넘지 않도록 합니다. v3 전송 프로토콜로 구버전 클라이언트와 방을 분리합니다. 두 사람 모두 최신 페이지로 접속하세요. 이는 친구 간 캐주얼 플레이용이며, 방장이 코드를 변조하는 것까지 방지하는 경쟁용 서버 검증은 아닙니다.

두 사람 모두 탭을 열어 두세요. 일시적인 끊김은 최대 5회 자동 재시도하고, 실패하면 **다시 연결하기**를 사용할 수 있습니다. 초기 연결·데이터 연결 시간 초과와 ICE 연결 상태를 감시합니다. 연결에 실패한 참가자가 자리를 영구 예약하지 않으며, 실제로 연결된 참가자의 자리만 보관합니다.

같은 탭을 새로고침하면 방장·참가자 역할과 현재 판을 복원합니다. 참가자는 같은 브라우저의 새 탭에서도 같은 코드로 재입장할 수 있습니다. 새 탭으로 재입장하면 이전 참가자 탭은 대전을 멈추며 자동으로 재접속하지 않습니다. 복원은 브라우저 저장 공간이 허용되어야 하며 24시간 유효합니다. **방 나가기**는 해당 탭의 복원을 지웁니다. 방장 탭을 완전히 닫은 뒤 새 탭에서 여는 경우는 복원을 보장하지 않습니다. 서버 영구 저장은 없습니다.

상태에는 재대결에서도 계속 증가하는 순번과 행동 응답 ID가 포함됩니다. 오래된 상태는 무시하고 동일한 상태가 다시 와도 선택한 기물을 지우지 않습니다. 참가자는 상태 동기화가 끝난 후에만 행동하며, 전송 실패를 성공으로 표시하지 않습니다.

PeerJS에 포함된 공용 STUN/TURN을 사용합니다. 일부 엄격한 NAT, 회사·학교·이동통신 네트워크에서는 공용 중계만으로 연결되지 않을 수 있습니다. 네트워크를 바꾸거나 자체 PeerServer/TURN을 구성해야 합니다. 공용 서비스의 가동률은 보장하지 않습니다.

## 개발

Node.js 20 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
```

- `engine.js`: DOM 없는 체스 규칙, 증강, 상태 reducer, AI
- `ui-rules.js`: 캐슬링 안내 및 킹→룩 조작의 공통 검증
- `network.js`: 방 생성, 접속, 상대 제한, 재연결, 데이터 채널
- `online-session.js`: 브라우저 복원, 참가자 식별, 오래된 상태 거부
- `app.js`: 한국어 UI, 대전 흐름, 동기화, 접근성
- `engine.test.js`, `network.test.js`: 규칙 및 온라인 프로토콜 테스트
- `index.html`, `style.css`, `viewport.css`, `abilities.css`, `favicon.svg`: 화면
- `peerjs.min.js`: 고정 버전 배포 파일, MIT 고지는 `PEERJS-LICENSE` 참고

GitHub Pages는 `main` 브랜치의 루트(`/`)를 배포합니다. 빌드 과정과 별도 서버는 필요하지 않습니다. 폰트만 Google Fonts에서 선택적으로 로드하며 로드되지 않으면 시스템 폰트로 표시됩니다.
